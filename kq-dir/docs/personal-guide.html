탭을 다루는 빠른 동작

01 / 폴더 → 새 탭

폴더를 새 탭으로 열기

리스트·트리에서 폴더를 휠클릭하거나 ⌘+더블클릭하세요. 폴더를 선택한 뒤 ⌘+Enter로도 열 수 있습니다.

02 / 탭 → 닫기

탭도 휠클릭으로 닫기

활성 탭과 비활성 탭 모두 바로 닫습니다. 마지막 탭을 닫으면 Untitled와 Open a folder 화면이 남습니다.

03 / 탭 → 복제

더블클릭하면 탭 하나 더

클릭한 탭의 바로 오른쪽에 복제 탭을 추가합니다. 현재 보고 있는 탭은 유지됩니다. 폴더·정렬·보기 방식 등 저장 가능한 탭 상태를 이어받습니다.

04 / 빈 탭 추가

＋ 버튼 또는 ⌘T

탭 스트립의 ＋ 버튼이나 ⌘T로 빈 탭을 추가합니다. 탭을 선택한 뒤 Open Folder…에서 원하는 폴더를 여세요.

새 탭을 열어도 현재 작업은 그대로. 폴더 열기·빈 탭 생성·복제·닫은 탭 복원은 현재 보고 있는 탭을 유지합니다. 준비한 새 탭을 클릭하면 그때 전환합니다.
