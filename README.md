# Claude 사용량 메뉴바 표시기

Claude Code를 이번 달에 얼마나 썼는지 **Mac 화면 맨 위 메뉴바**에 항상 보여줍니다.
매번 `/usage`를 입력하지 않아도 됩니다.

```
화면 오른쪽 위:   ✳︎ 59%        ← 월 한도 중 사용한 비율

아이콘 클릭 시:   월 사용액: $119.29 / $200.00
                  남은 금액: $80.71
```

- 3분마다 자동으로 새로 고침됩니다.
- 75% 이상 쓰면 **주황색**, 90% 이상 쓰면 **빨간색**으로 바뀝니다.

> 📌 **터미널에서 쓰는 Claude Code 기준입니다.**
> 터미널 Claude Code의 로그인 정보를 이용해 사용량을 확인합니다.
> Claude 앱(데스크톱 앱, 웹)만 쓰고 터미널 Claude Code를 쓰지 않는 경우에는 동작하지 않습니다.

---

## 설치 전 확인 (1분)

**터미널 Claude Code에 로그인되어 있어야 합니다.**
평소 터미널에서 `claude`로 Claude Code를 쓰고 있다면 이미 된 상태입니다. 바로 설치를 시작하세요.
처음이라면 터미널에서 `claude` 를 입력해 로그인을 한 번 마친 뒤 설치하세요.

---

## 설치하기 (5~15분)

### 1단계. 압축 풀고 폴더 옮기기

1. 받은 `Claude-Usage-Menubar.zip` 파일을 **더블클릭**합니다.
   `Cluade Usage`라는 폴더가 생깁니다.
2. 이 폴더를 **원하는 곳**에 둡니다. 어디든 괜찮습니다.
   - 예시: **Finder → 문서** 폴더로 끌어다 놓기 → `문서/Cluade Usage`
   - 바탕화면, 홈 폴더, 직접 만든 폴더 등 다른 곳도 됩니다.

> ⚠️ 설치가 끝난 뒤에는 이 폴더를 **옮기거나 지우지 마세요.** 메뉴바 아이콘이 사라집니다.
> (옮겨야 한다면 옮긴 뒤 설치를 한 번 더 하면 됩니다.)
>
> ⚠️ **iCloud Drive / 다운로드 폴더는 피하세요.** iCloud가 공간 확보를 위해 파일을 클라우드로만 남겨 두면 동작이 멈출 수 있고,
> 다운로드 폴더는 정리하다 실수로 지우기 쉽습니다.
> (시스템 설정 → Apple 계정 → iCloud → Drive 에서 "데스크탑 및 문서 폴더"가 켜져 있다면 문서·바탕화면도 iCloud 폴더입니다. 이때는 홈 폴더를 추천합니다.)

### 2단계. 터미널 열기

1. 키보드에서 **`⌘ Command` + `Space`** 를 누릅니다. (검색창이 뜹니다)
2. **`터미널`** 이라고 입력하고 **`Enter`** 를 누릅니다.
3. 글자를 입력할 수 있는 검은색(또는 흰색) 창이 열립니다.

### 3단계. 설치 명령 입력하기

1. 터미널 창에 아래 글자를 입력합니다. **`bash` 뒤에 띄어쓰기 한 칸**을 꼭 넣으세요.
   ```
   bash 
   ```
2. Finder에서 `Cluade Usage` 폴더를 열고, 안에 있는 **`install.sh` 파일을 터미널 창 안으로 끌어다 놓습니다.**
   파일 위치가 자동으로 입력되어 이렇게 보입니다 (문서 폴더에 둔 경우의 예시):
   ```
   bash /Users/내이름/Documents/Cluade\ Usage/install.sh
   ```
   폴더를 다른 곳에 두었다면 그 위치가 들어갑니다. 직접 칠 필요 없이 끌어다 놓기만 하면 됩니다.
3. **`Enter`** 를 누릅니다.

### 4단계. 화면 안내 따라가기

설치 중에 아래와 같은 것들이 나올 수 있습니다. **모두 정상입니다.**

| 이런 게 나오면 | 이렇게 하세요 |
|---|---|
| `Password:` 라고 나오고 멈춤 | **Mac 로그인 비밀번호**를 입력하고 `Enter`.<br>입력해도 **화면에 아무것도 안 보이는 게 정상**입니다. 그냥 치고 `Enter` 누르세요. |
| `Press RETURN/ENTER to continue` | `Enter` 를 누릅니다. |
| 글자가 한참 동안 계속 올라감 | 기다리세요. 처음 설치하는 Mac은 **10분 이상** 걸릴 수 있습니다. |
| "SwiftBar이(가) 키체인에 접근하려고 합니다" 창 | Mac 로그인 비밀번호 입력 후 **`항상 허용`** 클릭 |
| "SwiftBar이(가) 문서(또는 데스크탑) 폴더에 접근하려고 합니다" 창 | **`허용`** 클릭 (폴더를 둔 위치에 따라 안 뜰 수도 있습니다) |

터미널에 **`설치 완료.`** 가 나오면 끝입니다. 터미널 창은 닫아도 됩니다.

### 5단계. 확인하기

화면 **맨 위 오른쪽** (시계, 와이파이 아이콘 근처)에 **`✳︎ 숫자%`** 가 보이면 성공입니다. 🎉

> 💡 안 보인다면: 메뉴바에 아이콘이 너무 많으면 노트북 화면 가운데 **카메라 부분(노치)에 가려질 수** 있습니다.
> `⌘ Command` 키를 누른 채 다른 아이콘들을 오른쪽으로 끌어 자리를 비워 보세요.

### 6단계. (권장) 컴퓨터를 켤 때 자동 실행

이걸 안 하면 Mac을 재시동할 때마다 아이콘이 사라집니다.

1. 화면 왼쪽 위 **사과() 메뉴 → 시스템 설정** 을 엽니다.
2. **일반 → 로그인 항목** 으로 갑니다.
3. "로그인 시 열기" 아래의 **`+`** 버튼을 누릅니다.
4. **응용 프로그램 → SwiftBar** 를 선택하고 **`열기`** 를 누릅니다.

## 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| 메뉴바에 **`✳︎ !`** 표시 | 로그인이 잠깐 만료된 상태입니다 (아래 "Claude Code를 종료해도 되나요?" 참고). 터미널을 열어 `claude` 를 입력하고 `Enter` → 바로 `/exit` 로 나와도 됩니다. 아이콘 클릭 → `새로고침` 하면 다시 숫자가 나옵니다. |
| 메뉴바에 **`✳︎ ?`** 표시 | Claude Code 로그인이 안 되어 있습니다. 터미널에서 `claude` 를 실행해 로그인하세요. |
| 설치 중 **"Claude Code 로그인 정보가 없습니다"** | 위와 같습니다. `claude` 로그인 후 3단계부터 다시 하세요. |
| 설치 중 **"관리자 권한이 필요합니다"** | 이 Mac 계정으로는 프로그램 설치가 막혀 있습니다. IT 담당자에게 **"Homebrew 설치"** 를 요청하세요. |
| 설치 중 **"No such file or directory"** | `bash` 뒤에 띄어쓰기를 빠뜨렸거나, 파일을 잘못 끌어다 놓았습니다. 3단계를 다시 해 보세요. |
| 아이콘이 아예 안 보임 | ① 5단계 💡 확인 ② **시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더 → SwiftBar** 에서 스위치 켜기 ③ 3단계 설치 한 번 더 하기 |
| 숫자가 갱신이 안 되는 것 같음 | 아이콘 클릭 → **`새로고침`** |

## 자주 묻는 질문

**Q. 어떤 식으로 동작하는 앱인가요?**
세 가지가 함께 동작합니다.
1. **SwiftBar** (메뉴바 프로그램): 정해진 시간(기본 3분)마다 `plugin` 폴더 안의 스크립트를 실행합니다.
2. **스크립트** (`claude-usage.3m.sh`): 내 Mac 키체인에 저장된 Claude 로그인 정보로 Anthropic에 "이번 달 얼마 썼나요?"라고 물어봅니다.
   Claude Code에서 `/usage` 를 입력했을 때 보이는 것과 같은 정보입니다.
3. **메뉴바 표시**: 받은 사용액과 한도로 비율(%)을 계산해 `✳︎ 59%` 처럼 보여주고, 클릭하면 금액을 자세히 보여줍니다.

```
[SwiftBar] ─3분마다 실행→ [스크립트] ─로그인 정보로 조회→ [Anthropic]
     ↑                                                        │
     └──────────── ✳︎ 59% 표시 ←──── 사용액 / 한도 ←──────────┘
```

**Q. Claude 앱(데스크톱 앱)만 쓰는데 사용할 수 있나요?**
아니요. 이 도구는 **터미널 Claude Code의 로그인 정보**로 동작합니다.
Claude 앱은 로그인 정보를 따로 보관하기 때문에, 앱에만 로그인되어 있으면 메뉴바에 `✳︎ ?` 가 뜹니다.
터미널에서 `claude` 로 한 번 로그인하면 사용할 수 있지만, 터미널 Claude Code를 약 8시간 이상 안 쓰면 `✳︎ !` 로 바뀝니다 (아래 "종료해도 되나요?" 참고).

**Q. 지금 바로 최신 사용량을 보고 싶어요.**
메뉴바의 **`✳︎ 숫자%`** 를 클릭하고 **`새로고침`** 을 누르세요.
갱신 주기(3분 등)와 상관없이 **그 자리에서 바로** 새로 조회합니다.

**Q. 이걸 켜 두면 사용량(비용)이 더 나가나요?**
아니요. 3분마다 "지금 얼마 썼는지" 숫자만 확인하는 것이고, Claude에게 질문하는 게 아니라서 **비용이 전혀 들지 않습니다.**

**Q. 터미널의 Claude Code를 종료(`/exit`)해도 계속 보이나요?**
네, 보입니다. Claude Code를 켜 둘 필요는 없습니다.
다만 Claude 로그인 정보는 **마지막으로 Claude Code를 쓴 뒤 약 8시간** 동안만 유효합니다.
그 시간이 지나면 메뉴바가 `✳︎ !` 로 바뀝니다 (예: 퇴근 후 다음 날 아침).
터미널에서 `claude` 를 한 번 실행하면 다시 정상으로 돌아옵니다. 평소처럼 Claude Code를 쓰면 저절로 해결됩니다.

**Q. 내 계정 정보가 다른 사람에게 가나요?**
아니요. 내 Mac에 저장된 Claude 로그인 정보로 **Anthropic(Claude 회사)에만** 사용량을 물어봅니다. 다른 곳으로 보내거나 파일로 저장하지 않습니다.

**Q. SwiftBar가 뭔가요?**
메뉴바에 글자를 띄워 주는 무료 프로그램입니다. 설치 과정에서 자동으로 함께 설치됩니다.

**Q. 갑자기 안 되기 시작했어요.**
Claude 쪽 업데이트로 사용량을 확인하는 방식이 바뀌면 동작이 멈출 수 있습니다. 공유해 준 사람에게 알려 주세요.

## 갱신 주기 바꾸기 (선택)

기본은 **3분마다** 새로 고침입니다. **파일 이름**을 바꾸면 주기가 바뀝니다.

1. Finder에서 `Cluade Usage` → `plugin` 폴더를 엽니다.
2. `claude-usage.3m.sh` 파일을 클릭하고 **`Enter`** 를 누르면 이름을 고칠 수 있습니다.
3. 가운데 **`3m`** 부분만 원하는 값으로 바꾸고 `Enter`.

| 파일 이름 | 갱신 주기 |
|---|---|
| `claude-usage.1m.sh` | 1분마다 |
| `claude-usage.3m.sh` | 3분마다 (기본) |
| `claude-usage.10m.sh` | 10분마다 |
| `claude-usage.1h.sh` | 1시간마다 |

- 단위: `s` = 초, `m` = 분, `h` = 시간
4. SwiftBar를 껐다 켜야 적용됩니다. 터미널을 열고 아래 한 줄을 복사해서 붙여 넣은 뒤 `Enter`:
   ```
   killall SwiftBar; open -a SwiftBar
   ```

**⚠️ 유의사항**
- **`claude-usage`** 와 **`.sh`** 부분은 바꾸지 마세요. 가운데 숫자+단위만 바꿉니다. 점(`.`)도 지우면 안 됩니다.
- **1분보다 짧게(`30s` 등) 하지 마세요.** 공식적으로 공개되지 않은 방식으로 사용량을 확인하는 것이라, 너무 자주 물어보면 차단될 수 있습니다.
- 주기를 늘려도 급할 땐 언제든 아이콘 클릭 → **`새로고침`** 으로 바로 확인할 수 있습니다.
- 주기와 상관없이 **비용은 들지 않습니다.**
- 설치(`install.sh`)를 다시 해도 바꾼 이름은 유지됩니다. 단, 새 zip으로 폴더를 통째로 바꾸면 다시 3분이 됩니다.

## 삭제하기

1. 2단계처럼 터미널을 엽니다.
2. 아래 두 줄을 복사해서 붙여 넣고 `Enter`:
   ```
   brew uninstall --cask swiftbar
   defaults delete com.ameba.SwiftBar
   ```
3. `Cluade Usage` 폴더를 휴지통에 버립니다.
4. 6단계에서 로그인 항목에 추가했다면, 거기서 SwiftBar를 선택하고 **`−`** 버튼으로 뺍니다.
