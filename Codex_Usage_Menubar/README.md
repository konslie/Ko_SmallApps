# Codex 사용량 메뉴바 표시기

Mac 메뉴바에서 Codex 계정의 5시간·1주 잔여 사용량을 확인하는 앱입니다. 클릭하면 재설정 시각과 재설정 이용권 수를 볼 수 있습니다.

## 포함 파일

`Codex-Usage-Menubar.zip`에는 앱을 직접 빌드하는 데 필요한 Swift 소스, 설정 파일, 아이콘 리소스와 빌드 스크립트가 들어 있습니다. 미리 빌드된 앱은 포함하지 않습니다.

## 필요한 환경

- Apple Silicon Mac 및 macOS 13 이상
- ChatGPT 데스크톱 앱에서 Codex에 로그인한 계정
- Xcode Command Line Tools

## 빌드 및 실행

1. `Codex-Usage-Menubar.zip`을 다운로드해 더블클릭으로 압축을 풉니다.
2. 터미널을 열고 `bash `를 입력한 뒤, 압축을 푼 폴더 안의 `build.sh`를 터미널 창으로 끌어 놓고 Return 키를 누릅니다.
3. 빌드가 끝나면 압축을 푼 폴더의 `dist` 안에 있는 **Codex Usage.app**을 엽니다.
4. 처음 실행할 때 macOS가 앱을 확인할 수 없다는 안내를 표시하면 앱을 Control-클릭하고 **열기**를 선택합니다.

## 사용 방법

- 메뉴바의 Codex 아이콘 옆에서 5시간·1주 잔여량을 확인합니다.
- 아이콘을 클릭하면 상세 사용량, 재설정 시각, 재설정 이용권 수와 **새로고침** 버튼이 표시됩니다.
- ChatGPT 앱이 실행 중일 때 2분마다 자동으로 갱신합니다. 앱을 종료하면 마지막 수치를 유지하고, 다시 실행하면 갱신을 이어갑니다.

## 사용량 조회와 개인정보

앱은 Mac의 ChatGPT 데스크톱 앱에 로그인된 계정으로 로컬 Codex app-server에 사용량을 조회합니다. AI 답변을 요청하지 않으므로 이 조회 자체가 생성 토큰을 사용하지 않습니다. 마지막 사용량 스냅샷은 이 Mac의 앱 설정에 저장됩니다.
