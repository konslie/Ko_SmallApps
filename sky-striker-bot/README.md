# Sky Striker 봇

Python 3과 Playwright를 사용합니다.

```sh
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
python3 state_bot.py --login --headless
```

닉네임과 PIN은 실행 시 입력합니다. PIN은 저장하지 않습니다. 매번 입력하지 않으려면 `.env.example`을 `.env`로 복사해 `SKY_NICK`, `SKY_PIN`을 채우거나 같은 이름의 환경변수를 설정하세요. `.env`는 `.gitignore`에 포함되어 있습니다. 없는 닉네임을 넣으면 서버가 새 계정으로 등록하므로, 봇이 "새 닉네임으로 등록되었습니다"를 출력하면 오타를 확인하세요. 로그인에 실패하면 서버 메시지를 출력하고 종료합니다. 봇이 PIN을 다루지 않게 하려면 `--manual-login`으로 실행하세요. 브라우저 창에 설정 창이 열리면 직접 로그인하고, 봇은 로그인이 확인된 뒤 게임을 시작합니다(`--login`, `--headless`와 함께 쓸 수 없음). macOS에서 화면을 보려면 `python3 state_bot.py --login`을 실행하세요. Linux에서 창을 띄우려면 그래픽 디스플레이가 필요합니다. 기본(`--browser auto`)은 설치된 Chrome이 있으면 Chrome, 없으면 Playwright Chromium입니다. `--browser chrome`과 `--browser chromium`으로 고정할 수 있습니다.

기본 실행에는 시간 제한이 없습니다. 게임 오버 또는 올클리어까지 진행합니다. 시험용 시간 제한은 `--seconds`로 명시할 때만 적용됩니다.

## 운용 전략

- 아이템: x2(모든 점수에 최대 x8), OD(연사 2배), ★(무적)를 가장 먼저 먹습니다. PW는 무기 레벨이 상한보다 낮거나 레벨 하락까지 10초 미만이면, HP는 바닥나면 같은 순위로 올라갑니다. 그 밖의 PW·실드·HP(가득이면 500점)는 0.75초 안에 닿을 때만 먹습니다.
- 행성은 지나가면 점수와 아이템이 사라지므로 보스보다 먼저 쏩니다. 보스 등장 중에도 행성이 있으면 행성을 쏩니다.
- 보스·중간보스가 내려오는 동안(도착 전에는 쏘지 않음) 산탄으로 바짝 붙어 공격하고, 도착 약 0.5초 전에 빠집니다.
- 보스가 도착하면 라이트닝으로 바꾸고, 보스전에서 사거리 밖으로 밀려나면 유도탄으로 바꿉니다. 웨이브에서는 라이트닝을 유지합니다.
- 실드가 있거나 무적일 때는 앞으로 나가 적이 쏘기 전에 잡습니다. 보스전에서 ★·초신성·성역의 무적이 2.5초 넘게 남으면 산탄으로 근접합니다(맞은 뒤 무적으로는 근접하지 않음).
- 보너스 스테이지에서는 HP를 감수하고 앞으로 나가 행성을 부숩니다. HP 2 이하이고 실드·무적이 없으면 평소처럼 피합니다.
- 카드: 무기 레벨이 상한 미만이면 PW 2배(레벨 하락 없음)를 가장 먼저, 그다음 점수 사냥, 세라프면 필살기 보급, PW 2배, 행운 순으로 고릅니다.
- 스킬 연계: 스킬 효과는 기체를 바꿔도 이어집니다. 보스가 도착하면 노바 초신성(6초, 피해 ×1.5·연사 2배) → 끝날 즈음 세라프 성역(5초) → 오리진 빅뱅(3초) 순으로 무적을 이어 붙이고 원래 기체로 돌아옵니다. 노바·세라프가 해금돼야 하고(보통 34스테이지~, 지옥은 처음부터), 필살기 횟수와 능력 재사용 대기는 모든 기체가 같이 씁니다.
- 웨이브(잡몹 구간)에서는 라이트닝이 해금된 뒤 산탄·유도탄을 쓰지 않고, 다른 무기를 들고 있으면 바로 라이트닝으로 돌아갑니다.
- 맨 아래(화면 85% 아래)로 밀리고 위쪽 가까이에 적과 적 탄이 12개 이상이면 스킬로 뚫습니다: 노바 초신성·랩터 대시가 준비돼 있으면 Space, 노바가 해금돼 있으면 노바로 바꿔 초신성, 아니면 필살기(B).
- 블레이드는 마지막 방패로만 씁니다: HP 1·실드 0·무적 아님·위험 큼이고, 초신성(노바로 바꿔서라도)·대시·필살기가 모두 없을 때만 바꾸고, 위기를 넘기면 원래 무기로 돌아갑니다. 위기 상황에서도 스킬을 먼저 씁니다.
- 필살기는 다음 스테이지로 넘어가지 않으므로 보스전에서 탄막이 빽빽할 때나 보스 HP 25% 미만일 때 씁니다.
- 기체는 세라프, 오리진, 노바, 타이탄, 와이번, 팬텀, 팔콘 순으로 고릅니다(그 판에서 해금된 것만). 랩터(HP -1)는 고르지 않습니다.

## 에이전트(Claude Code·Codex)가 실행할 때

- `--headless` 없이 실행해 Chrome 창을 띄웁니다. 설치된 Chrome이 있으면 운영체제와 관계없이 Chrome을 쓰고, 없으면 Playwright Chromium을 씁니다(`--browser chromium`으로 강제 가능). 사람이 플레이를 직접 볼 수 있게 하기 위함입니다.
- 5·10·15…스테이지가 끝날 때마다, 그리고 게임이 끝날 때 로그에 `[5스테이지 보고]`로 시작하는 한 줄이 나옵니다. 실행한 에이전트는 이 줄을 감시해 **사용자와의 대화에 그대로 옮겨 남깁니다.** 같은 내용이 `stage-report-<난이도>.md`에도 누적됩니다.
- 게임오버 직후 바로 종료하지 않습니다. 랭킹 제출 응답을 기다린 뒤 봇이 스스로 끝날 때까지 두세요.

## 측정 기록

실행하면 `telemetry-<난이도>.json`에 무기별 실측 DPS(보스 HP 감소량, 등장 중/공격 중 구분), 보스전 결과(등장 중 처치 여부, 도착 후 소요 시간), 보너스 점수와 x8 유지 비율, 스테이지별 x8 유지 비율, 무기 레벨 하락 시점을 남깁니다. 같은 내용이 로그에 `기록 …` 줄로 출력됩니다. 경로는 `--telemetry`로 바꿀 수 있습니다.

## 난이도와 브라우저 프로필

항상 해금된 가장 어려운 난이도(지옥 → 어려움 → 보통)로 시작합니다. 난이도 해금은 서버가 아니라 브라우저 저장소에만 남으므로, 봇은 같은 폴더의 `.browser-profile`을 계속 이어 씁니다(로그인 상태도 유지됨, `.gitignore` 포함). 매번 새 프로필을 쓰려면 `--fresh-profile`을 붙이세요. 이 경우 보통만 열려 있습니다.

게임이 끝나면 로그인한 계정은 서버의 랭킹 제출 응답을 최대 30초 기다리고, 응답 뒤 3초 더 화면을 유지한 다음 종료합니다.

## 휴대폰 진행 상태

```sh
python3 monitor.py
```

같은 Wi-Fi의 휴대폰에서 `http://맥북의LAN주소:8765`에 접속하면 스테이지, 점수, 체력, 장비를 확인할 수 있습니다. 이 서버는 공개된 게임 진행 정보만 제공합니다. 일반 파일 디렉터리를 노출하지 않습니다. 인터넷 외부에서는 직접 접근할 수 없으며, 별도 VPN 또는 화면 공유가 필요합니다. 봇은 2초마다 `status.json`을 갱신합니다. Mac이 잠들면 갱신과 접속이 중단됩니다.

게임 주소에 클라우드에서 접속할 수 있어야 플레이가 가능합니다. 연결 가능 여부는 실행 환경에 따라 다릅니다. 봇은 브라우저에서 게임 상태를 읽고 키보드로 조작합니다. 기본으로 `.browser-profile`을 이어 쓰며, `--resume` 옵션은 게임 서버의 이어하기 기록을 사용합니다.
